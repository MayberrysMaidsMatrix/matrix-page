# Mayberry's Matrix: page file

This repository holds the **page design** for Mayberry's Maids' internal sales tool.
Google Apps Script loads `Index.html` from here each time the Matrix is opened.

What is NOT here, on purpose:
- No customer information. All business data lives in a private Google Sheet.
- No team photos. They are stored in the Google script, not in this public repository.
- No passwords or keys.

Sign-in and permissions are handled by Google Workspace, not by this page.

Rule: only Gil edits this repository. Keep two-step verification turned on for the account.
Every change goes in `CHANGELOG.md`.
